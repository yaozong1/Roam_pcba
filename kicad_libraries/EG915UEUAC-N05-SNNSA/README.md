# EG915U-EU (variant EG915UEUAC-N05-SNNSA)  —  Quectel LTE Cat 1 module

## Package
LCC + LGA, ~22.5 x 17.7 x 2.3 mm. Custom footprint — there is no
stock equivalent. You will need a dedicated download.

## Sources
- SnapEDA has the related EG915 variants (free with signup):
  https://www.snapeda.com/parts/EG915NEUAG-N06-SGNSA/Quectel/view-part/
  Then change the part number suffix in the search box to find -EUAC.
- Quectel: design files are sometimes attached to the Hardware Design
  document on https://www.quectel.com/product/lte-standard-eg915u/
  — log in and check the "design materials" tab.
- Community: https://github.com/snegovick/kicad_libs has a small
  quectel.lib but only contains the older M95 (no EG915).

I could not find a free, dedicated KiCad library for EG915U on GitHub.
