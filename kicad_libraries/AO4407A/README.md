# AO4407A  —  Alpha & Omega 30 V P-channel MOSFET

## Package
SOIC-8 (150 mil body, 1.27 mm pitch)

## Files in this folder
- `AO4407A.lib`                       — legacy KiCad symbol (imports fine into KiCad 7/8)
- `AO4407A_SOIC-8_150MIL.kicad_mod`   — SOIC-8 footprint, 150 mil body

Source: https://github.com/gin-cc/KiCad-Library (lc_kicad_lib)

## Alternative: stock KiCad
The stock library SOIC-8 footprint `Package_SO:SOIC-8_3.9x4.9mm_P1.27mm`
is equivalent. The stock symbol library has generic single P-MOSFET
symbols you can label as AO4407A — pin numbering matches.
